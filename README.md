# Audiovisual social perception from shape animations
This repository contains experiment code, data, and analysis code for the project. 

This project aims to examine how does sound intensity affect whether people judging two moving dots as playing or fighting with each other.

Exp1 and exp1_replication contain the materials for the web-based experiments. To run the experiment demo, download exp1 and open index.html. Exp1_replication has a different sound adjustment task before experiment starts.

Exp1_data and exp1_rep_data contain the experiment data.

Data_analysis contains all analysis code.
